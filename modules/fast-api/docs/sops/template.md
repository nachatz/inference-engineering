## When

The trigger: the alert, symptom, or change that means someone should run this.

## Before you start

- Access, tools, and state the steps assume.

## Steps

1. One action per step, with the exact command.

   ```bash
   just recipe
   ```

2. What the output should look like, so the reader knows the step worked.

## Done when

The checks that prove the procedure succeeded.

| --- | --- | --- |
